RN2C

RADIO • VOIX • CHAT • RÉSEAU TOR

RN2C est une radio communautaire en direct et un espace de discussion, accessible uniquement par le réseau Tor. La radio s'écoute sans compte ; pour parler, un pseudonyme suffit, sans email ni numéro de téléphone.
Accès via adresse .onion — nécessite Tor Browser ou Brave.

Générique
# Tor Browser
sudo apt install -y torbrowser-launcher && torbrowser-launcher
# Brave
sudo curl -fsSLo /usr/share/keyrings/brave.gpg https://brave-browser-apt-release.s3.brave.com/brave-browser-archive-keyring.gpg
echo "deb [arch=amd64 signed-by=/usr/share/keyrings/brave.gpg] https://brave-browser-apt-release.s3.brave.com/ stable main" | sudo tee /etc/apt/sources.list.d/brave.list
sudo apt update && sudo apt install -y brave-browser
# Tor Browser
sudo dnf install -y torbrowser-launcher && torbrowser-launcher
# Brave
sudo dnf config-manager --add-repo https://brave-browser-rpm-release.s3.brave.com/brave-browser.repo
sudo rpm --import https://brave-browser-rpm-release.s3.brave.com/brave-core.asc
sudo dnf install -y brave-browser
# Tor Browser + Brave via AUR
yay -S tor-browser brave-bin
# Tor Browser
sudo zypper install torbrowser-launcher && torbrowser-launcher
# Brave
sudo zypper ar https://brave-browser-rpm-release.s3.brave.com/brave-browser.repo
sudo zypper ref && sudo zypper in brave-browser
flatpak install flathub com.github.micahflee.torbrowser-launcher
flatpak install flathub com.brave.Browser
# Tor Browser — tar.xz
tar -xf tor-browser-linux64-*.tar.xz && cd tor-browser && ./start-tor-browser.desktop
# Brave — AppImage
chmod +x brave-browser-*.AppImage && ./brave-browser-*.AppImage
Pour le chat vocal RN2C, préfère Brave + Tor.
